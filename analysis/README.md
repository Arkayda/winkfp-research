# Reverse-Engineering Analysis & Decompiled Artifacts

This directory contains raw reverse-engineering artifacts, Ghidra decompiler pseudocode (`.c`), disassembly annotations, calling convention records, and structure layouts organized by subsystem.

---

## 1. Directory Structure

* **`kr_api/`**: Central authentication orchestrator (`FUN_0041c920`), KrApi entry point (`FUN_004617c0`, `FUN_004b95a0`), and MSVC LCG RNG (`FUN_00461800`).
* **`get_auth_key/`**: Key container resolution engine (`FUN_004b8fe0`), line parser, and ATBALGO table structures.
* **`crypto/`**:
  * `symmetric/`: MD5 initialization, round compression, IV tables (`0x605160`), and symmetric key lookup tables (`FUN_004b9f50`, `FUN_004bbdb0`).
  * `simple/`: Proprietary 8-byte Simple cipher transformation loops (`FUN_004ba1b0`, `FUN_004ba080`).
  * `asymmetric/`: High-level asymmetric entry points and dword-swapping loops (`FUN_004b9e30`, `FUN_004b8a70`).
  * `rsa/`: Low-level RSA modular exponentiation, Montgomery reduction, and multi-precision integer math (`FUN_004bb720`, `FUN_004bb780`).
* **`vdle/`**: VDLE command dispatcher (`FUN_004a1f80`), OPPS configuration (`FUN_004a5b60`), keep-alive (`FUN_004a5960`), and block transmission (`FUN_004668b0`).
* **`ediabas/`**: Global EDIABAS dispatch pointers (`DAT_00735398`), `apiJob` wrapper (`FUN_00490250`), and `ebas32.dll` master password verification routines.
* **`obd32/`**: Export contracts and command dispatch analysis for `OBD32.dll` (K-Line serial driver).

---

## 2. Research Note on Decompiler Pseudocode

The `.c` files in this directory are decompilation artifacts generated by Ghidra 12.1.4:
* They represent static observation artifacts (`L1`).
* Variable types and function signatures reflect reverse-engineering reconstruction and may contain Ghidra decompiler heuristics (such as injected `alloca_probe` stubs).
* These files serve as analytical reference material for independent verification. They are **not** compiled directly; all operational code is implemented independently in `reconstruction/`.
