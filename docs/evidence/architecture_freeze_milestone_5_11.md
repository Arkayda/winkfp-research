- Hard safety interlocks preventing write, session, security, or flash commands from entering the read-only execution path.

## 2. Canonical Architecture

The reconstructed read-only stack enforces a strictly layered, fail-closed design with unified request building, response validation, and semantic decoding:

```
===================================================================================================
                                CANONICAL READ-ONLY ARCHITECTURE
===================================================================================================

       [ EDIABAS Replay / Application Layer ]
            reconstruction/ediabas/replay.py
            - EdiabasJobReplayEngine.execute_job()
            - EdiabasTelegram (logical _TEL_AUFTRAG: [Format, Target, Tester, Payload])
            - EvidenceDomain Isolation (FACTORY_TRACE vs PHYSICAL_EGS_FIXTURE)
                                    |
                                    v
       [ Canonical Diagnostic Pipeline ]
            reconstruction/ediabas/pipeline.py
            - CanonicalPipeline.execute()
            - SgbdJobDefinition (10FLASH specification & constraints)
            - ResponseValidator (Fail-closed framing, length, addressing, SID/SubID, CS)
               /                                      \
              v                                        v
   [ Canonical Request Builder ]             [ Fail-Closed Response Validator ]
   - build_request() -> Wire DS2             - validate_response()
   - format byte + target + tester + CS      - checks framing, length, NRCs, SID
              |                                        ^
              |                                        |
              +---------------> [ Fixture Data ] ------+
                                (TraceFixture / JSON)
                                         |
                                         v
       [ SGBD Semantic Parsers ]
            reconstruction/ediabas/sgbd.py
            - decode_10flash_ident()
            - decode_10flash_phys_hw_nr()
            - decode_10flash_seriennummer()
            - decode_10flash_aif_s23()
            - decode_10flash_zif() / zif_backup() / hw_referenz() / daten_referenz()
                                         |
                                         v
       [ Structured Replay Result ]
            - EdiabasJobResult / SgbdJobResult
            - Fields, status ("OKAY"), orthogonal evidence flags
===================================================================================================
```

### Architectural Rules & Invariants
1. **Telegram vs Wire Frame Separation**:
   - `EdiabasTelegram`: Represents the internal EDIABAS kernel buffer (`_TEL_AUFTRAG`). Contains format byte, target address, tester address, and payload, but **no trailing checksum byte**.
   - Physical DS2 Wire Frame: Generated by `EdiabasTelegram.to_wire_frame()` or `CanonicalPipeline.build_request()`. Contains the trailing additive checksum byte (`sum(bytes[0..N]) & 0xFF`).
2. **Canonical DS2 Request Addressing Semantics**:
   - In Request Frames (TX): `byte[1] = destination / target ECU address` (`0x18` for EGS, `0x78` for factory gateway), `byte[2] = source / tester address` (`0xF1`).
   - In Response Frames (RX): `byte[1] = destination / tester address` (`0xF1`), `byte[2] = source / target ECU address` (`0x18` or `0x78`).
3. **Hard Evidence Domain Isolation**:
   - `FACTORY_TRACE`: Fixed target `0x78`. Attempting to force target `0x18` raises `ValueError`. Always reports `physical_trace_exists = False`, `directly_resolved = False`.
   - `PHYSICAL_EGS_FIXTURE`: Fixed target `0x18`. Attempting to force target `0x78` raises `ValueError`. Always reports `physical_trace_exists = True`, `directly_resolved = True`.
   - Evidence domains cannot be silently merged, upgraded, or downgraded.
4. **Service Isolation ($23 vs $1A86)**:
   - `AIF_LESEN`: Canonical SGBD job requiring KWP2000 service `0x23` (`ReadMemoryByAddress`). If presented with a `1A 86` response, it fails closed with `ERROR_SGBD_USES_SERVICE_0x23_NOT_0x1A86`.
   - `AIF_READ_BENCH_ALIAS`: Strictly isolated reconstruction alias modeling the physical KWP2000 `1A 86` bench probe.

## 7. Safety Boundary & Interlocks

The read-only reconstruction stack enforces strict, defense-in-depth safety boundaries guaranteeing that hazardous or mutating services can never be accidentally invoked:

1. **Replay Whitelist Filtering**:
   - `CanonicalPipeline.get_job()` only indexes the 9 explicitly declared read-only jobs.
   - Any attempt to invoke session controls (`0x10`), security access (`0x27`), routine controls (`0x31`), reset (`0x11`), flash erase (`0x34`), or download (`0x36`) raises `NotImplementedError` immediately.
2. **Fail-Closed SID & SubID Gate**:
   - `ResponseValidator.validate_response()` enforces strict expected response SIDs (`0x5A`, `0x62`, `0x63`).
   - If an unexpected negative response (NRC) or invalid SID is returned, the pipeline fails closed before executing semantic decoding.
3. **Physical Hardware Probe Gate**:
   - `tools/kdcan_hardware_probe.py` restricts probes strictly to `["aif", "tester_present", "ident", "physical_hw_nr"]` via `argparse.choices`.
   - Requires explicit `--confirm-readonly-hardware` flag.
   - Prohibits flashing, erasing, reset, or authentication commands.

## 8. Known UNKNOWN Areas (Research Backlog)

The following areas remain unobserved on physical hardware and represent candidate subjects for future controlled research:

1. **`SERIENNUMMER_LESEN` on physical EGS ($1A $89)**:
   - Observed in factory trace on gateway target `0x78`.
   - Behavior on physical EGS target `0x18` (whether it returns positive `5A 89` or NRC `7F 1A 12`) remains unverified on physical hardware.
2. **`AIF_LESEN` on physical EGS ($23 ReadMemoryByAddress)**:
   - SGBD bytecode strictly specifies service `0x23` for reading AIF records at memory offset `0x00000007`.
   - Whether the active flash application on 0479S90T641Z permits memory reads via $23 in default diagnostic session, or requires an extended session / security access, is physically unverified.
3. **ZIF & Reference Jobs on physical EGS ($22 $2500–$2504)**:
   - Behavior of Common Identifier reads ($22) on physical EGS target `0x18` is physically unobserved.
4. **Mutating Services ($10, $27, $31, $34, $36, $37, Flash, Erase)**:
   - Completely unexecuted on hardware; preserved behind safety interlocks.

     ```python

         def transceive_ds2(self, request_wire: bytes, timeout: float = 1.0) -> bytes: ...
     ```

   - Connect the runtime transport between `EdiabasJobReplayEngine` (request builder) and `ResponseValidator` (response parser).
   - Do **NOT** modify canonical job definitions (`job_model.py`), semantic parsers (`sgbd.py`), or evidence classifications.
